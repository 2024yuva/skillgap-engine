# Skillora Assets

This directory contains assets for the Skillora landing page.

## Company Logos

Place the following company logo files in this directory:

- `fedex-logo.svg` - FedEx company logo
- `orange-logo.svg` - Orange company logo  
- `microsoft-logo.svg` - Microsoft company logo
- `amazon-logo.svg` - Amazon company logo
- `walmart-logo.svg` - Walmart company logo
- `att-logo.svg` - AT&T company logo

## Usage

The landing page will automatically display these logos in the spinning company section. Make sure the logo files are properly formatted SVG files for best quality.

## Image Guidelines

- Use SVG format for scalability
- Ensure logos are properly licensed for use
- Maintain consistent sizing (the component will handle responsive scaling)
- Use transparent backgrounds where appropriate
